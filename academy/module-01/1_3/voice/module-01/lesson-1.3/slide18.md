## Type

## Goal

Проверить понимание ограничений насоса для чистой воды.

## Plain text

Теперь проверка. Можно ли без риска использовать насос для чистой воды при перекачивании стоков с включениями? Подумайте о конструкции проточных каналов и рабочего колеса. Оцените возможные последствия: засорение, снижение производительности, перегрев или поломку. Выберите ответ без подсказки по интонации. После проверки запомните общий принцип: допустимый состав жидкости и размер частиц должны соответствовать требованиям производителя конкретного насоса.
