# Slide 08 — Расход воды и производительность

## Type
calculation

## Goal
Производительность

## Plain text
Производительность показывает, сколько воды насос способен подать за минуту. Оценивайте не все приборы в доме, а реалистичный сценарий одновременной работы. Например, душ, кухонный кран и полив. Небольшой запас полезен, но чрезмерно мощная модель не делает систему автоматически лучше.
