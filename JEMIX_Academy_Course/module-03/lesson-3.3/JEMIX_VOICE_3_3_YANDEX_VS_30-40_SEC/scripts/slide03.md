# Slide 03 — Что такое поверхностный насос

## Type
theory

## Goal
Теория

## Plain text
Поверхностный насос устанавливается вне воды, рядом с источником. Он забирает воду через всасывающую линию и подаёт её потребителю. Главное ограничение связано с глубиной всасывания. Даже мощный двигатель не поможет, если зеркало воды находится глубже допустимого значения.
