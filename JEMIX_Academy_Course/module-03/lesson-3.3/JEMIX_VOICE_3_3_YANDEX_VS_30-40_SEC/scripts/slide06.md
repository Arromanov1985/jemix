# Slide 06 — Ключевые характеристики

## Type
theory

## Goal
Параметры

## Plain text
При выборе поверхностного насоса проверяют четыре параметра. Глубина всасывания показывает, сможет ли насос забрать воду. Производительность определяет доступный расход. Напор отвечает за подъём воды и преодоление потерь в трубах. Мощность двигателя важна, но сама по себе не заменяет остальные характеристики.
