# Slide 21 — Алгоритм подбора

## Type
scheme

## Goal
Объяснить содержание слайда живым языком технического наставника.

## Plain text
Алгоритм подбора состоит из четырёх последовательных шагов. Сначала определите источник воды и допустимую глубину всасывания. Затем рассчитайте одновременный расход по реальному сценарию использования. После этого определите требуемый напор с учётом высоты подъёма, длины труб, фильтров и давления в дальней точке. И только на последнем шаге сравнивайте модели, предусматривая разумный запас. Такой порядок защищает от самой частой ошибки — выбора станции по знакомому названию или одной максимальной характеристике без проверки всего объекта.
