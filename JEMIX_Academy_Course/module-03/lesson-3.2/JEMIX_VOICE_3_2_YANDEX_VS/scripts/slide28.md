# Slide 28 — Итоги урока

## Type
summary

## Goal
Объяснить содержание слайда живым языком технического наставника.

## Plain text
Подведём итог. Насосная станция автоматически подаёт воду и поддерживает давление в бытовой системе. Подбор всегда начинается с источника, глубины всасывания, одновременного расхода и требуемого напора. Компактные модели подходят для небольших задач. Производительные станции выбирают для нескольких одновременно работающих точек. Модели с повышенным напором нужны для сложной магистрали, а Смарт-решение — для более стабильного давления. Не ориентируйтесь только на мощность или максимальные цифры. Правильный выбор — это модель, характеристики которой подтверждены условиями конкретного объекта.
