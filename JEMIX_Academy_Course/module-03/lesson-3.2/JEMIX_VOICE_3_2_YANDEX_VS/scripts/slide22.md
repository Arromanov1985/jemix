# Slide 22 — Практический кейс

## Type
case

## Goal
Объяснить содержание слайда живым языком технического наставника.

## Plain text
Представьте дом с кухней, душем, стиральной машиной и поливом. Несколько точек могут работать одновременно, поэтому основной запрос — высокий расход воды без сильной просадки давления. В такой ситуации можно рассматривать А-Пэ-Пэ-Эн сто тридцать. Но рекомендация становится окончательной только после проверки глубины источника, этажности, требуемого напора и потерь в трубопроводе. Если дом двухэтажный или магистраль длинная, одной высокой производительности может оказаться недостаточно. Продавец должен подтвердить, что модель подходит по двум параметрам одновременно: и по расходу, и по напору.
