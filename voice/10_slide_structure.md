# JEMIX Voice Standard v1.0 — структура озвучки слайдов

Цель: единая структура дикторских сценариев для разных типов слайдов JEMIX Academy.

## Общие правила

Каждый слайд должен иметь:

1. Цель озвучки.
2. Обычный текст.
3. SSML.
4. Ожидаемую длительность.
5. QA-статус.

## Типы слайдов

### 1. Вступление урока

Задача: объяснить, зачем нужен урок.

Структура:

```text
Здравствуйте.
Сегодня разберём тему.
После урока вы сможете выполнить практическое действие.
Главное — связать задачу клиента с правильным подбором.
```

Целевая длительность: 20–30 секунд.

### 2. Что нужно понять

Задача: задать рамку урока.

Структура:

```text
В этом уроке есть несколько ключевых мыслей.
Первая...
Вторая...
Третья...
Именно они помогают продавцу не ошибиться при подборе.
```

Целевая длительность: 25–35 секунд.

### 3. Теория

Задача: объяснить одно понятие.

Структура:

```text
Главная мысль такая.
Простое объяснение.
Практический смысл для продавца.
Короткий вывод.
```

Целевая длительность: 25–40 секунд.

### 4. Схема / карта выбора

Задача: провести слушателя по логике выбора.

Структура:

```text
Посмотрите на схему.
Начинаем с задачи клиента.
Затем проверяем среду.
После этого уточняем параметры.
И только потом переходим к комплекту.
```

Целевая длительность: 30–45 секунд.

### 5. Вопросы продавца

Задача: показать, какие данные собрать.

Структура:

```text
Перед подбором продавец должен задать несколько вопросов.
Первый вопрос...
Второй вопрос...
Третий вопрос...
Ответы превращают просьбу клиента в задачу подбора.
```

Целевая длительность: 30–45 секунд.

### 6. Практический кейс

Задача: применить правило к ситуации клиента.

Структура:

```text
Представьте ситуацию.
Клиент говорит...
Риск в том, что...
Правильный шаг продавца...
Вывод...
```

Целевая длительность: 35–55 секунд.

### 7. Как это звучит

Задача: показать живую фразу продавца.

Структура:

```text
Клиент формулирует запрос.
Продавец не спорит и не угадывает.
Он уточняет условия.
Затем переводит разговор к подбору комплекта.
```

Целевая длительность: 25–40 секунд.

### 8. Ошибка в подборе

Задача: показать неправильную и правильную логику.

Структура:

```text
Типовая ошибка — выбрать насос только по одному параметру.
Правильный подход — проверить задачу, среду и условия.
Так продавец снижает риск возврата.
```

Целевая длительность: 25–40 секунд.

### 9. Красные флаги

Задача: остановить опасное обещание.

Структура:

```text
А теперь важный момент.
Если появляется красный флаг, не обещайте модель сразу.
Сначала соберите данные.
После этого можно переходить к решению.
```

Целевая длительность: 25–40 секунд.

### 10. Быстрая проверка

Задача: настроить на вопрос.

Структура:

```text
Теперь короткая проверка.
Не вспоминайте термин.
Проверьте логику решения.
Выберите вариант, который безопаснее для клиента.
```

Целевая длительность: 15–25 секунд.

### 11. Итоги урока

Задача: закрепить правила.

Структура:

```text
Подведём итог.
Первое...
Второе...
Третье...
В реальной продаже это помогает подобрать не просто насос, а рабочее решение.
```

Целевая длительность: 25–35 секунд.
