# JEMIX Voice Standard v1.0 — SSML для SaluteSpeech

Цель: единый стандарт разметки дикторских сценариев JEMIX Academy для реалистичной озвучки в SaluteSpeech.

## Главный принцип

Голос не должен читать слайд дословно. Озвучка объясняет, дополняет и удерживает внимание слушателя.

## Базовый шаблон

```xml
<speak>
Здравствуйте.
<break time="600ms"/>
Сегодня разберём тему урока.
<break time="800ms"/>
Главная мысль этого экрана — одна.
<break time="400ms"/>
<emphasis level="strong">Важное правило произносится с акцентом.</emphasis>
<break time="700ms"/>
Теперь посмотрим, как это работает на практике.
</speak>
```

## Паузы

| Ситуация | Пауза |
|---|---|
| После обычного предложения | `<break time="350ms"/>` |
| После важной мысли | `<break time="600ms"/>` |
| Перед новым смысловым блоком | `<break time="800ms"/>` |
| Перед практическим примером | `<break time="900ms"/>` |
| Перед вопросом к слушателю | `<break time="700ms"/>` |
| После фразы «Запомните» | `<break time="500ms"/>` |

## Акценты

Акцент используем только для ключевых правил.

```xml
<emphasis level="strong">Поверхностный насос не подходит, если зеркало воды глубже восьми метров.</emphasis>
```

Не выделять акцентом каждое второе предложение. Один экран — один главный акцент.

## Темп

Для большинства учебных экранов:

```xml
<prosody rate="92%"> ... </prosody>
```

Для тестовых инструкций можно использовать нейтральный темп без `prosody`.

## Длина фрагмента

| Тип слайда | Целевая длительность |
|---|---:|
| Вступление | 20–30 секунд |
| Теория | 25–40 секунд |
| Схема | 30–45 секунд |
| Практический кейс | 35–55 секунд |
| Красные флаги | 25–40 секунд |
| Быстрая проверка | 15–25 секунд |
| Итоги урока | 25–35 секунд |

## Правила текста

1. Не использовать символы `%`, `м³/ч`, `л/мин`, `Ø`, `кВт` в финальном SSML.
2. Числа и единицы писать словами по `02_numbers_and_units.md`.
3. Модели JEMIX писать по `03_models_jemix.md`.
4. Сокращения писать по `04_abbreviations.md`.
5. Предложения делать короткими: до 12–16 слов.
6. Не ставить две длинные паузы подряд.

## Типовые шаблоны

### Вступление

```xml
<speak>
Здравствуйте.
<break time="600ms"/>
В этом уроке разберём ...
<break time="700ms"/>
После урока вы сможете ...
</speak>
```

### Красные флаги

```xml
<speak>
А теперь важный момент.
<break time="600ms"/>
Если клиент сообщает тревожный признак, не называйте модель сразу.
<break time="500ms"/>
<emphasis level="strong">Сначала уточните условия работы насоса.</emphasis>
<break time="700ms"/>
Так продавец снижает риск ошибки и возврата.
</speak>
```

### Перед тестом

```xml
<speak>
Отлично.
<break time="500ms"/>
Основные принципы мы разобрали.
<break time="500ms"/>
Теперь проверьте себя на коротких вопросах.
</speak>
```

## Контроль перед синтезом

- SSML начинается с `<speak>` и заканчивается `</speak>`.
- Нет необработанных технических символов.
- Нет слишком длинных предложений.
- Важная мысль выделена не более одного раза.
- Длительность соответствует типу слайда.
