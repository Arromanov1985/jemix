# JEMIX Voice Standard v1.0 — числа и единицы измерения

Назначение файла: правила записи чисел, размеров и единиц измерения для естественного синтеза речи в SaluteSpeech.

Главное правило: в дикторских сценариях не оставляем символы, дроби и технические сокращения в исходном виде. Пишем словами.

## Базовые правила

| Не писать в сценарии | Писать для озвучки |
|---|---|
| 8 м | восемь метров |
| 220 В | двести двадцать вольт |
| 50 Гц | пятьдесят герц |
| 25 л/мин | двадцать пять литров в минуту |
| 3 м³/ч | три кубических метра в час |
| 1,5 кВт | полтора киловатта |
| 0,75 кВт | семьдесят пять сотых киловатта |
| 32 мм | тридцать два миллиметра |
| Ø32 | диаметр тридцать два миллиметра |
| 1" | один дюйм |
| 1 1/4" | один и одна четверть дюйма |

## Длина, глубина, высота

| Запись | Озвучка |
|---|---|
| 5 м | пять метров |
| 8–9 м | восемь — девять метров |
| до 8 м | до восьми метров |
| более 8 м | больше восьми метров |
| 40 м | сорок метров |
| 120 м | сто двадцать метров |

Рекомендация: для обучения продавцов чаще использовать разговорную форму.

Пример:

- вместо «глубина всасывания до восьми метров»;
- лучше: «если зеркало воды глубже восьми метров, поверхностный насос уже не подходит».

## Давление

| Запись | Озвучка |
|---|---|
| 1 бар | один бар |
| 2 бара | два бара |
| 3 бар | три бара |
| 3,5 бар | три с половиной бара |
| 6 атм | шесть атмосфер |
| 0,2 МПа | две десятых мегапаскаля |

В учебных сценариях предпочтительно использовать «бар» или «атмосферы» в зависимости от контекста курса.

## Расход и производительность

| Запись | Озвучка |
|---|---|
| 20 л/мин | двадцать литров в минуту |
| 50 л/мин | пятьдесят литров в минуту |
| 3 м³/ч | три кубических метра в час |
| 4,5 м³/ч | четыре с половиной кубических метра в час |
| 0,6 м³/ч | шесть десятых кубического метра в час |

Рекомендация: для продавцов объяснять расход через бытовые сценарии.

Пример:

> Если одновременно работает душ, кран на кухне и стиральная машина, расход воды становится выше. Поэтому насос подбирают не только по глубине, но и по потреблению дома.

## Правило для моделей с цифрами

В моделях дроби и слэши не читаем как математические выражения.

| Запись | Озвучка |
|---|---|
| WRS-25/40 | W R S двадцать пять сорок |
| WRF-25/60 | W R F двадцать пять шестьдесят |
| ATJET-100 | А-Ти-Джет сто |
| GP-600 | Джи-Пи шестьсот |

## Контроль качества

Перед генерацией аудио проверить:

- нет ли символов м³, л/мин, кВт, В, Гц в финальном дикторском тексте;
- все дроби записаны словами;
- все диапазоны читаются естественно;
- модели насосов читаются по словарю моделей;
- единицы измерения согласованы по падежам.
