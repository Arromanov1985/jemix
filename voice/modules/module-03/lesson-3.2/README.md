# Voice сценарии — Модуль 3, урок 3.2

Урок: Поверхностные насосы.

Назначение: первый эталонный урок для проверки JEMIX Voice Standard в SaluteSpeech.

## Статус

- Формат: TXT + SSML.
- Голос: наставник.
- Цель: проверить стиль, паузы, ударения и естественность речи.
- Статус: draft.

| 03 | rule | slide03.txt, slide03.ssml | draft |

## Следующий шаг

После прослушивания этих трёх слайдов в SaluteSpeech нужно утвердить:

- произношение JEMIX;
- чтение серии ATJET;
- длительность пауз;
- общий темп диктора;
- стиль «наставник, а не диктор презентации».

После утверждения можно масштабировать сценарии на остальные слайды и модули.
