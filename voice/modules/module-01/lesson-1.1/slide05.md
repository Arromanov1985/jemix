# Slide 05 — Мини-диалог

## Plain text
Клиент говорит: нужен насос на дачу.

Это слишком общий запрос. По нему нельзя сразу выбрать модель.

Правильный ответ продавца — не угадывать, а уточнить задачу.

Нужно спросить: насос нужен для подачи воды в дом, для полива, для откачки воды или для повышения давления?

Так продавец переводит разговор из общего желания клиента в конкретную задачу подбора.
