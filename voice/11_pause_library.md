# JEMIX Voice Standard v1.0 — библиотека пауз

Цель: единая система пауз для SaluteSpeech, чтобы голос звучал естественно и не торопился.

## Основные паузы

| Пауза | SSML | Когда использовать |
|---:|---|---|
| 250 мс | `<break time="250ms"/>` | короткая синтаксическая пауза |
| 350 мс | `<break time="350ms"/>` | конец обычного предложения |
| 500 мс | `<break time="500ms"/>` | после слова «Важно» или «Запомните» |
| 600 мс | `<break time="600ms"/>` | после ключевой мысли |
| 700 мс | `<break time="700ms"/>` | перед вопросом или выводом |
| 800 мс | `<break time="800ms"/>` | переход к новому смысловому блоку |
| 900 мс | `<break time="900ms"/>` | перед практическим примером |
| 1100 мс | `<break time="1100ms"/>` | редкая драматическая пауза перед критическим правилом |

## Где использовать короткие паузы

Короткие паузы нужны внутри объяснения.

Пример:

```xml
Поверхностный насос работает рядом с источником воды.
<break time="350ms"/>
Он забирает воду через всасывающую магистраль.
```

## Где использовать средние паузы

Средние паузы нужны после важной мысли.

```xml
Запомните главное правило.
<break time="500ms"/>
Если зеркало воды глубже восьми метров, поверхностный насос не подходит.
```

## Где использовать длинные паузы

Длинные паузы нужны перед новым блоком.

```xml
Теперь посмотрим на практический пример.
<break time="900ms"/>
Клиент говорит: мне нужен насос для колодца.
```

## Чего избегать

Не использовать подряд:

```xml
<break time="900ms"/>
<break time="900ms"/>
```

Не ставить длинную паузу после каждого предложения. Это делает речь рваной.

## Ритм типового слайда

```text
Вводная фраза
350 мс
Объяснение
500 мс
Главная мысль
700 мс
Практический вывод
```

## Ритм красного флага

```text
А теперь важный момент
600 мс
Тревожный признак
700 мс
Что нельзя делать
500 мс
Что нужно сделать
```

## Ритм практического кейса

```text
Представьте ситуацию
700 мс
Запрос клиента
500 мс
Риск
700 мс
Правильное действие продавца
500 мс
Вывод
```

## Контроль

Перед синтезом проверить:

- нет слишком длинных пауз без причины;
- важные правила отделены паузой;
- тестовые вопросы не звучат затянуто;
- один экран не превышает целевую длительность.
