# JEMIX Voice Standard v1.0 — модели JEMIX

Назначение файла: единое произношение серий, моделей и буквенно-цифровых обозначений JEMIX в сценариях озвучки.

Важно: этот файл требует финального утверждения внутри TWG/JEMIX, потому что часть правил относится к фирменному произношению.

## Основное правило

В аудиосценариях не оставляем модель в техническом виде, если она может быть прочитана синтезатором неверно.

Не так:

```text
ATJET-100
```

Так:

```text
А-Ти-Джет сто
```

## Правила чтения буквенных серий

Есть два возможных стандарта чтения латинских букв.

### Вариант A — английское чтение букв

| Серия | Озвучка |
|---|---|
| WRS | Дабл-ю Ар Эс |
| WRF | Дабл-ю Ар Эф |
| GS | Джи Эс |
| GP | Джи Пи |
| TF | Ти Эф |
| TOP | Топ |
| ECO | Эко |

### Вариант B — русское чтение букв

| Серия | Озвучка |
|---|---|
| WRS | Вэ Эр Эс |
| WRF | Вэ Эр Эф |
| GS | Джи Эс |
| GP | Джи Пи |
| TF | Тэ Эф |
| TOP | Топ |
| ECO | Эко |

## Предварительно принятый стандарт для курса

Для курса используем более понятное продавцам чтение:

- WRS — Вэ Эр Эс;
- WRF — Вэ Эр Эф;
- GS — Джи Эс;
- GP — Джи Пи;
- ATJET — А-Ти-Джет;
- ATQB — А-Ти-Кью-Би;
- TOP — Топ;
- ECO — Эко.

Если компания утвердит английское чтение WRS/WRF, заменить во всех сценариях централизованно по этому файлу.

## Правила для сценариев

1. В визуальном слайде модель можно оставить как `WRS-25/40`.
2. В дикторском тексте модель пишется словами: `Вэ-Эр-Эс двадцать пять сорок`.
3. Если модель не важна для конкретного слайда, лучше говорить серию: `насос серии Вэ-Эр-Эс`.
4. Если модель может перегрузить новичка, использовать категорию: `циркуляционный насос`.

## Проверка перед синтезом

Перед генерацией аудио проверить:

- все модели заменены на дикторскую форму;
- слэши в моделях не читаются как «дробь»;
- дефисы не вызывают паузу внутри серии;
- одна и та же серия читается одинаково во всех модулях;
- спорные серии WRS/WRF утверждены с ответственным по продукту.
