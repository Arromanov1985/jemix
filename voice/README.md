# JEMIX Voice SDK

JEMIX Voice SDK — подсистема репозитория JEMIX Academy для подготовки реалистичной озвучки курса через SaluteSpeech.

## Задача

Сделать голос курса единым, понятным и профессиональным:

- правильные ударения;
- единое произношение моделей JEMIX;
- естественные паузы;
- SSML под SaluteSpeech;
- короткие дикторские фрагменты;
- контроль качества перед генерацией MP3.

## Как использовать

1. Берём слайд урока.
2. Пишем обычный дикторский текст.
3. Проверяем термины по словарю.
4. Преобразуем текст в SSML.
5. Генерируем аудио в SaluteSpeech.
6. Проверяем аудио по QA.
7. Добавляем MP3 в урок.

## Основной стандарт

Голос не читает экран. Голос объясняет экран.

Пример:

На слайде написано:

```text
Поверхностный насос
До восьми метров
Для колодца
```

Диктор говорит:

```text
Поверхностный насос подходит, когда источник находится рядом и зеркало воды не глубже восьми метров. Это ограничение связано не с мощностью двигателя, а с физикой всасывания воды.
```

## Минимальный стандарт качества

Аудио готово к публикации, если:

- модели JEMIX произносятся одинаково;
- нет ошибок ударений;
- текст не дублирует слайд дословно;
- голос звучит как наставник;
- длительность соответствует типу слайда;
- QA отмечен как `ok`.
