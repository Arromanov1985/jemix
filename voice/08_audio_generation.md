# JEMIX Voice Standard v1.0 — генерация аудио

Цель: описать конвейер подготовки аудио для JEMIX Academy через SaluteSpeech.

## Конвейер

```text
Слайд урока
  ↓
Дикторский текст
  ↓
SSML SaluteSpeech
  ↓
Синтез MP3
  ↓
Прослушивание
  ↓
QA
  ↓
Публикация в LMS / H5P
```

## Папки

Рекомендуемая структура:

```text
voice/
  modules/
    module-03/
      lesson-3.2/
        slide01.md
        slide01.txt
        slide01.ssml
        slide02.md
        slide02.txt
        slide02.ssml
        audio/
          slide01.mp3
          slide02.mp3
        voice_qa.md
```

## Форматы файлов

### `.md`

Редакторская версия. Содержит:

- название слайда;
- цель озвучки;
- обычный дикторский текст;
- комментарии для редактора;
- ожидаемую длительность.

### `.txt`

Чистый текст без SSML. Нужен для проверки смысла и редактуры.

### `.ssml`

Финальная версия для SaluteSpeech.

### `.mp3`

Сгенерированный аудиофайл.

## Именование

Использовать двухзначную нумерацию:

```text
slide01.txt
slide01.ssml
slide01.mp3
```

Не использовать кириллицу в именах аудиофайлов.

## Профили голосов

Базовые роли:

```yaml
voice_profiles:
  narrator:
    role: Наставник
    speed: 0.92
    emotion: calm

  customer:
    role: Клиент
    speed: 1.00
    emotion: neutral

  examiner:
    role: Проверка знаний
    speed: 0.90
    emotion: serious
```

## Настройки для SaluteSpeech

Финальные параметры зависят от выбранного голоса. До утверждения голоса использовать стандарт:

- темп: умеренный;
- интонация: спокойная;
- стиль: наставник;
- паузы по `05_ssml_rules.md`;
- ударения по `01_pronunciation_dictionary.md`.

## Генерация одного слайда

1. Взять содержание слайда.
2. Написать дикторский текст по `06_voice_style.md`.
3. Проверить термины и модели.
4. Создать SSML.
5. Сгенерировать MP3.
6. Прослушать.
7. Исправить SSML, если голос звучит неестественно.
8. Зафиксировать статус в `voice_qa.md`.

## Генерация урока

1. Сгенерировать все `.txt`.
2. Проверить стиль и смысл.
3. Сгенерировать все `.ssml`.
4. Выполнить QA по `07_quality_check.md`.
5. Сгенерировать MP3.
6. Прослушать выборочно все слайды и полностью сложные слайды.
7. Записать результаты в `voice_qa.md`.

## Генерация модуля

Для каждого урока модуля:

- проверить наличие сценариев;
- проверить длительность;
- проверить одинаковое произношение моделей;
- собрать аудиофайлы;
- подготовить manifest.

## Manifest

Для каждого урока рекомендуется файл `audio_manifest.yml`:

```yaml
lesson: 3.2
voice_profile: narrator
slides:
  - slide: 01
    ssml: slide01.ssml
    audio: audio/slide01.mp3
    duration_sec: 28
    qa: ok
```

## Правило обновления

Если меняется словарь произношения, нужно пересмотреть все сценарии, где встречается термин.

Если меняется модель чтения серии, например WRS, нужно обновить все `.txt` и `.ssml` по курсу.

## Минимальный стандарт качества

Аудио готово к публикации, если:

- все файлы MP3 сгенерированы;
- нет ошибок ударений;
- модели читаются единообразно;
- длительность не перегружает урок;
- голос звучит как объяснение, а не чтение таблицы.
