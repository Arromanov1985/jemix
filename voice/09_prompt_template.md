# JEMIX Voice Standard v1.0 — prompt template

Цель: единый промпт для генерации дикторских сценариев и SSML под SaluteSpeech.

## Основной промпт

```text
Ты пишешь дикторский сценарий для корпоративного курса JEMIX Academy.

Задача: создать озвучку для одного слайда.

Стиль:
- опытный технический наставник;
- объясняет, а не читает слайд;
- помогает продавцу принять решение;
- речь живая, спокойная, уверенная;
- без канцелярита;
- без перегруза цифрами.

Требования:
- длительность 20–40 секунд;
- все числа и единицы писать словами;
- модели JEMIX читать по словарю моделей;
- сокращения раскрывать;
- использовать SSML для SaluteSpeech;
- добавить паузы;
- один главный акцент на слайд;
- не обещать модель без проверки условий.

Входные данные:
Модуль: {module}
Урок: {lesson}
Слайд: {slide_number}
Тип слайда: {slide_type}
Заголовок: {title}
Текст на экране: {screen_text}
Цель слайда: {slide_goal}

Выведи результат в формате:
1. Короткая цель озвучки.
2. Обычный дикторский текст.
3. SSML.
4. Ожидаемая длительность.
5. QA-чеклист.
```

## Prompt для слайда «Теория»

```text
Создай сценарий для теоретического слайда.

Не повторяй текст слайда дословно.
Сначала назови главную мысль.
Затем объясни её простыми словами.
После этого покажи, как это помогает продавцу.
В конце дай короткий вывод.
```

## Prompt для слайда «Схема»

```text
Создай сценарий для слайда со схемой.

Проведи слушателя по схеме слева направо.
Объясни только ключевые элементы.
Не перечисляй всё подряд.
В конце сформулируй главное правило.
```

## Prompt для практического кейса

```text
Создай сценарий для практического кейса.

Начни с ситуации клиента.
Покажи риск ошибки.
Объясни, какие данные должен собрать продавец.
Заверши безопасным решением.
```

## Prompt для красных флагов

```text
Создай сценарий для слайда «Красные флаги».

Тон чуть серьёзнее обычного.
Объясни, почему нельзя сразу подбирать модель.
Назови тревожный признак.
Дай безопасный следующий шаг.
```

## Prompt для тестового слайда

```text
Создай короткую инструкцию перед проверочным вопросом.

Не подсказывай правильный ответ.
Настрой слушателя на выбор решения.
Длительность до двадцати секунд.
```

## QA prompt

```text
Проверь дикторский сценарий по JEMIX Voice Standard.

Проверь:
- ударения;
- модели JEMIX;
- числа и единицы;
- сокращения;
- длину предложений;
- естественность речи;
- отсутствие опасных обещаний;
- корректность SSML;
- длительность.

Верни:
- OK / NEEDS FIX;
- список ошибок;
- исправленную версию, если нужно.
```
