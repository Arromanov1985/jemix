# JEMIX Voice Standard v1.0 — QA перед синтезом

Цель: проверить каждый дикторский сценарий до генерации аудио в SaluteSpeech.

## Быстрый чек-лист

Перед синтезом каждый файл `.ssml` должен пройти проверку.

### 1. Структура SSML

- [ ] Файл начинается с `<speak>`.
- [ ] Файл заканчивается `</speak>`.
- [ ] Все теги закрыты.
- [ ] Нет вложенных тегов, которые могут сломать синтез.
- [ ] Нет двух длинных пауз подряд.

### 2. Числа и единицы

- [ ] Нет `м³/ч`.
- [ ] Нет `л/мин`.
- [ ] Нет `кВт`.
- [ ] Нет `В`, `Гц`, `мм`, `м` в технической записи.
- [ ] Все числа записаны словами.
- [ ] Диаметры и резьбы читаются по `02_numbers_and_units.md`.

### 3. Модели JEMIX

- [ ] Все модели читаются по `03_models_jemix.md`.
- [ ] Нет необработанных обозначений вроде `WRS-25/40`.
- [ ] Слэши в моделях не читаются как дроби.
- [ ] Серии WRS, WRF, ATJET, ATQB читаются одинаково во всём курсе.

### 4. Сокращения

- [ ] Все сокращения обработаны по `04_abbreviations.md`.
- [ ] Нет необработанных `IP54`, `DN25`, `PN10`, `PVC`.
- [ ] Если сокращение не нужно слушателю, оно заменено смысловым объяснением.

### 5. Ударения

Проверить по `01_pronunciation_dictionary.md`:

- [ ] гидроаккумулятор;
- [ ] производительность;
- [ ] манометр;
- [ ] кавитация;
- [ ] колодезный;
- [ ] скважинный;
- [ ] циркуляционный;
- [ ] водоотведение;
- [ ] точка водоразбора.

### 6. Длина и темп

- [ ] Вступление: 20–30 секунд.
- [ ] Теория: 25–40 секунд.
- [ ] Схема: 30–45 секунд.
- [ ] Кейсы: 35–55 секунд.
- [ ] Проверка: 15–25 секунд.
- [ ] Нет фрагментов длиннее одной минуты без необходимости.

### 7. Стиль

- [ ] Диктор объясняет, а не читает слайд.
- [ ] Есть связь с задачей продавца.
- [ ] Есть практический вывод.
- [ ] Нет канцелярита.
- [ ] Нет необоснованных обещаний клиенту.
- [ ] Нет перегруза цифрами.

### 8. Безопасность консультации

- [ ] В сценарии нет рекомендации модели без уточнения условий.
- [ ] При красных флагах диктор говорит сначала собрать данные.
- [ ] При сложной задаче есть фраза про проверку условий.
- [ ] Не обещаем, что насос решит проблему, если неизвестны параметры источника.

## Финальная проверка на слух

После генерации MP3 проверить:

- [ ] естественность голоса;
- [ ] правильность ударений;
- [ ] паузы не слишком длинные;
- [ ] акценты не звучат резко;
- [ ] модели читаются понятно;
- [ ] нет ощущения робота;
- [ ] диктор не торопится;
- [ ] общий смысл понятен без просмотра слайда.

## Критические ошибки

Если найдена хотя бы одна из этих ошибок, аудио переделывается:

- модель прочитана неверно;
- единица измерения прочитана как символ;
- ударение искажает смысл;
- диктор даёт опасную рекомендацию;
- текст выходит за пределы нормальной длительности;
- голос звучит как чтение таблицы.
