# JEMIX Voice Standard v1.0 — библиотека интонаций

Цель: задать единый эмоциональный режим диктора для курса JEMIX Academy.

## Базовый образ

Диктор — спокойный технический наставник. Он говорит уверенно, доброжелательно и без рекламного давления.

## Режимы речи

| Режим | Где использовать | Как звучит |
|---|---|---|
| calm | теория и вводные слайды | спокойно и ровно |
| focus | ключевое правило | чуть медленнее, с акцентом |
| warning | красные флаги и ошибки | серьёзнее и осторожнее |
| practice | клиентские кейсы | живее и ближе к консультации |
| check | тесты | нейтрально, без подсказки |
| summary | итоги | уверенно и собранно |

## Calm

Используется для большинства учебных экранов.

Пример: «Поверхностный насос устанавливается рядом с источником воды и забирает воду через всасывающую линию.»

## Focus

Используется для одного главного правила на слайде.

Пример: «Запомните главное правило. Если зеркало воды глубже восьми метров, поверхностный насос не подходит.»

SSML:

```xml
Запомните главное правило.
<break time="500ms"/>
<emphasis level="strong">Если зеркало воды глубже восьми метров, поверхностный насос не подходит.</emphasis>
```

## Warning

Используется на слайдах с красными флагами.

Пример: «Если клиент не знает глубину скважины, не называйте модель сразу. Сначала нужно уточнить параметры источника.»

## Practice

Используется в практических кейсах.

Пример: «Представьте ситуацию. Клиент просит насос помощнее. Продавец не должен угадывать модель. Сначала он уточняет условия работы.»

## Check

Используется перед проверкой знаний.

Пример: «Теперь выберите вариант, который безопаснее для клиента.»

## Summary

Используется на итоговых слайдах.

Пример: «Подведём итог. Продавец подбирает не просто насос, а рабочее решение под задачу клиента.»

## Правила

1. Не использовать слишком бодрый рекламный тон.
2. Не делать голос монотонным.
3. Не превращать ошибку клиента в обвинение.
4. В красных флагах говорить серьёзно, но спокойно.
5. В тестах не подсказывать ответ интонацией.
6. На одном слайде использовать один основной режим и один короткий акцент.

## QA

После генерации аудио проверить:

- теория звучит понятно;
- кейс звучит как реальная консультация;
- красный флаг звучит серьёзно;
- тест не подсказывает ответ;
- итог звучит как закрепление материала.
