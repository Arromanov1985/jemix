# JEMIX Voice Standard v1.0 — шаблоны диалогов

Цель: задать единый формат коротких учебных диалогов для курса JEMIX Academy.

Диалог помогает показать, как продавец уточняет задачу клиента и переводит разговор к правильному подбору оборудования.

## Роли

- Наставник: объясняет логику и подводит итог.
- Клиент: формулирует обычный запрос.
- Продавец: задаёт уточняющие вопросы.

## Базовый шаблон

```text
Наставник: Представьте ситуацию.
Клиент: Мне нужен насос помощнее.
Продавец: Давайте сначала уточним источник воды, глубину и расход.
Наставник: Продавец не угадывает модель. Он собирает данные и снижает риск ошибки.
```

## SSML-шаблон

```xml
<speak>
Представьте ситуацию.
<break time="700ms"/>
Клиент говорит: мне нужен насос помощнее.
<break time="600ms"/>
Продавец отвечает: давайте сначала уточним источник воды, глубину и расход.
<break time="700ms"/>
Так продавец не угадывает модель, а собирает данные для правильного подбора.
</speak>
```

## Типовые ситуации

### Уточнение задачи

```text
Клиент: Нужен насос для дома.
Продавец: Для какой задачи: водоснабжение, откачка воды, канализация или отопление?
Наставник: Первый шаг — определить задачу клиента. Без этого нельзя выбрать группу насоса.
```

### Скважина

```text
Клиент: У меня скважина, нужен насос.
Продавец: Какая глубина скважины и на каком уровне стоит вода во время работы?
Наставник: Для скважины важна не только общая глубина, но и рабочий уровень воды.
```

### Колодец

```text
Клиент: Хочу поставить насос рядом с колодцем.
Продавец: Какая глубина до зеркала воды?
Наставник: Если зеркало воды глубже восьми метров, поверхностный насос не подходит.
```

### Откачка воды

```text
Клиент: Нужно откачать воду из подвала.
Продавец: Вода чистая или с песком и включениями?
Наставник: Для откачки важна среда. Насос подбирают не только по напору.
```

### Отопление

```text
Клиент: Нужно, чтобы отопление лучше работало.
Продавец: Нужно движение теплоносителя по контуру или повышение давления воды?
Наставник: Циркуляционный насос не поднимает воду из источника. Он двигает теплоноситель по системе отопления.
```

### Цена

```text
Клиент: Почему так дорого?
Продавец: Мы подбираем не только насос, но и комплект, который защищает систему и снижает риск поломки.
Наставник: Продавец объясняет ценность комплекта через безопасность и срок службы.
```

## Правила

1. Диалог короткий: три-четыре реплики.
2. Клиент говорит простыми словами.
3. Продавец не спорит, а уточняет.
4. Наставник завершает выводом.
5. Не обещать модель без проверки условий.
6. Не использовать диалог там, где нужен короткий тест.

## QA

Проверить:

- запрос клиента похож на реальный;
- продавец задаёт правильный первый вопрос;
- нет обещания модели без условий;
- вывод закрепляет правило;
- диалог укладывается в 30–45 секунд.
