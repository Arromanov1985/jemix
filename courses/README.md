# JEMIX Academy — H5P course files

Этот каталог предназначен для хранения готовых H5P-уроков курса JEMIX Academy.

## Структура

```text
courses/
├── module1/
│   ├── 1_1/
│   │   ├── lesson.h5p
│   │   └── README.md
│   └── ...
├── module2/
│   └── ...
└── module3/
    ├── 3_1/
    ├── 3_2/
    ├── 3_3/
    ├── 3_4/
    ├── 3_5_1/
    ├── 3_5_2/
    └── 3_6_1/
```

## Правило именования

Каждый урок хранится в отдельной папке:

```text
courses/module3/3_6_1/lesson.h5p
courses/module3/3_6_1/README.md
```

## Важно

GitHub-коннектор ChatGPT в этом чате умеет создавать и изменять только UTF-8 текстовые файлы через Contents API. Бинарные `.h5p` архивы нужно добавлять в репозиторий обычным `git add` / `git push` или через GitHub Web UI.

В этом каталоге уже подготовлена структура и manifest со всеми сгенерированными уроками. Готовые `.h5p` файлы из чата нужно положить в соответствующие папки под именем `lesson.h5p`.
